# Faceless Reclaimation

Public-facing home for Faceless Reclaimation material.

This repository may hold landing pages, zines, public fragments, story-reclaiming language, lived-experience artifacts, and Reclaimation-facing digital offerings.

It is not the canonical Perspection governance repository.

## Project role

This repo may contain:

- Faceless Reclaimation landing pages
- Zine and artifact pages
- Public-facing story/reclaiming material
- Digital product pages
- Lived-experience fragments prepared for publication
- Links to related ecosystem tools when clearly labeled

## What belongs elsewhere

| Material | Belongs in |
|---|---|
| Perspection governance, refusal rules, copy lint, audits | `7u4n3r/Perspection` |
| Trinity-specific framework/site material | `7u4n3r/trinity-framework-site` |
| Working tool experiments, Manus build fragments, UI drafts | `7u4n3r/Trinity-tools` |
| Neutral analysis/reference material | `7u4n3r/system-analysis-reference` |

## Boundary rule

Faceless Reclaimation may carry story, fire, artifact energy, and public-facing Reclaimation language.

It does not become Perspection governance.
It does not become Trinity doctrine.
It does not absorb every tool.

Interoperable does not mean merged.

## Current status

This repo began as a landing page for the Faceless Reclaimation zine and is now bounded as the home for Reclaimation-facing public material.

See `PROJECT_BOUNDARY.md` before adding or migrating material.
