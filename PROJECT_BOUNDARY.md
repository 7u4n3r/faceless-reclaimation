# PROJECT_BOUNDARY.md

## Project identity

This repository is the public-facing home for Faceless Reclaimation material.

It may hold landing pages, zines, product pages, public fragments, story-reclaiming language, lived-experience artifacts, and Reclaimation-facing digital offerings.

## This project is not

- It is not the canonical Perspection governance repository.
- It is not the Trinity Framework site.
- It is not the neutral System Analysis Reference container.
- It is not a catch-all bucket for every ecosystem build.

## Allowed material

- Faceless Reclaimation landing pages
- Zines and artifact pages
- Lived-experience public writing
- Story-reclaiming language and offers
- Reclaimation-facing digital product pages
- Links to related tools when clearly labeled

## Not allowed material

- Canonical Perspection governance rules as if this repo owns them
- Trinity Framework copy as the main identity
- Neutral legal/property/system evidence files as the main identity
- Unlabeled Manus exports from unrelated projects
- Copy that merges Faceless Reclaimation, Perspection, Trinity, and Living Survival Guide into one purpose

## Related but separate

- `7u4n3r/Perspection` is the canonical governance/reference surface.
- `7u4n3r/trinity-framework-site` is reserved for Trinity-specific site material.
- `7u4n3r/Trinity-tools` may hold working tool builds and implementation experiments.
- `7u4n3r/system-analysis-reference` may hold neutral analysis/reference material.

## Operating rule

Faceless Reclaimation may carry story, fire, and public-facing artifact energy.

It does not become Perspection governance.
It does not become Trinity doctrine.
It does not absorb every tool.
